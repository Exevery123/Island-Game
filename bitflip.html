Bit-Flip Clock

Generate distance-r binary codes, design a dial of light-tiles, then flip through the strings. Each lit/unlit combination is a symbol — name it and save it to your Dictionary, where you can also compose symbols into saved clocks.

1 Generate binary strings

Keeps every length-n string whose pairwise Hamming distance is ≥ r, scanning all 2n strings in order.

2 Design your clock dial

Drag the body to move, drag a corner to resize. Add exactly n tiles. Order (#0, #1, …) is what each bit controls.

Connect mode: click one tile, then another, to link them. Click a link to remove it. Strings where a lit tile has no lit neighbor get filtered out.

3 View & save symbols

A 1 lights tile #i; a 0 leaves it dark. Save the current combination as a named symbol.
